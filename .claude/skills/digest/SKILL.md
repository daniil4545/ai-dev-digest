# Дайджест

Спека: `docs/plans/claude-digest.md`, источники: `docs/plans/claude-digest-sources.md`. Скилл готовит материал для чтения; посты и мнения пишет владелец, их не предлагать.

## 1. Кандидаты

```bash
.venv/bin/python -m src.main collect > <scratchpad>/candidates.json
```

- JSON-массив `{title, url, source, published_at, summary, score}`: новости за `MAX_ITEM_HOURS` (72 часа), которых ещё не было в дайджестах
- stderr: строка `WARNING` - источник со сбоем, запомнить для отчёта
- Пустой массив: сказать «новых новостей нет», файл не создавать, дальше не идти

## 2. Отбор

Читатель - LLM-инженер, который пишет Telegram-канал про AI в разработке.

- Вверх: coding agents, developer tools, автоматизация разработки, практика AI-инженерии (evals, RAG, агенты в проде, инференс, свои модели), практические обновления и новые AI-инструменты
- Вниз: общий хайп, маркетинг, партнёрства и тарифы без технической сути, crypto, новости не про AI и разработку (большая часть HN)
- `score` (очки HN, звёзды GitHub) - сигнал интереса, не решение; у RSS он 0
- До 10 новостей для разбора. Сильных меньше - меньше, без добивки слабыми
- До 10 пунктов в «Коротко»
- Одна новость из нескольких источников - один пункт со ссылкой на оригинал

## 3. Оригиналы

Каждую новость из разбора открыть через WebFetch, запросы параллельно.

- Не открылась (403 - так отвечает openai.com, paywall, пустая страница): найти среди кандидатов пересказ той же новости (часто Habr) и разбирать по нему с пометкой; пересказа нет - по `summary` из JSON с пометкой
- Видео YouTube и выпуски подкаста: WebFetch видит только описание, разбор по нему с пометкой
- Факты, цифры и имена - только из прочитанного текста. Чего в тексте нет, не писать

## 4. Файл

Путь `digests/YYYY-MM-DD.md` с сегодняшней датой. Файл уже есть - `YYYY-MM-DD-2.md`, `-3` и дальше; существующий не перезаписывать. Url копировать из JSON без изменений: по ним `mark` отмечает показанное.

Строка «Оригинал не открылся» - только когда так и было. Язык разбора русский, простой и конкретный. Без символов `→ ← — × ✓ ✗` и эмодзи.

```markdown
# Дайджест 30.09.2026

## 1. <Заголовок по-русски: суть новости>

<источник>, <ДД.ММ> - <url>
Оригинал не открылся (403), разбор по пересказу: <url пересказа>

**Что произошло.** 2-4 предложения по оригиналу: факты и цифры.
**Почему это важно LLM-инженеру.** 1-3 предложения: что меняется в работе и выборе инструментов.
**Вопрос для поста.** Один вопрос, над которым стоит подумать.

## Коротко

- <заголовок по-русски>: одна строка сути. <url>
```

## 5. Отметка и отчёт

```bash
.venv/bin/python -m src.main mark digests/<файл>
```

В чат, без пересказа дайджеста:
- путь к файлу, число разборов и пунктов в «Коротко»
- источники со сбоем из stderr
- новости, у которых оригинал не открылся
